# Agent Wormhole — media package

Brand assets built on the liquid-glass look: the white Lensed Field mark,
optionally seated in a translucent glass disc.

## Marks

| File | Use |
| --- | --- |
| `mark-white.svg` | Master mark, fixed white. Any dark surface. |
| `mark-glass.svg` | Master glass badge (disc + ring + mark). Avatars, app icons. |
| `mark-white-{1024,512,256}.png` | Transparent white mark rasters. |
| `mark-glass-{1024,512,256,64}.png` | Transparent glass badge rasters. |

## Lockups

| File | Use |
| --- | --- |
| `lockup-transparent.png` (2400×720) | Glass badge + Instrument Serif italic wordmark, transparent. |
| `lockup-black.png` (2400×720) | Same on solid black. |
| `banner-1280x640.png` | Social banner: lockup + tagline over the nebula still. |

## Motion

| File | Use |
| --- | --- |
| `logo-loop.gif` (800×800) | The field assembling: rings slide off-axis toward the throat, the dot glides into place and pulses. |
| `nebula-loop.mp4` (1280×720, 16 s) | Seamless glass-nebula drift. Section backgrounds. |
| `guard-loop.mp4` (1280×720, 14 s) | Terminal loop: `guard` refuses a self-replicating edit mid-write. |

Rules of use: the mark is always white; the disc is always dark glass; no
recoloring, no drop shadows, no rotation. Below 24 px use the simplified
favicon variants in the site app directory instead — the five-ring field
mushes at tiny sizes.

Type: Instrument Serif Italic (wordmark) · Barlow (supporting text).
